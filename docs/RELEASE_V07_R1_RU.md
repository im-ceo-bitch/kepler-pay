# SpyderPay Core 0.7.1 — блок 2, pre-license

Накопительно включает v0.6 и v0.7: тарифы, комиссионные проводки,
внутренний полный chargeback с независимыми решениями и исполнением.
Версия схемы 7. Реальные расчёты запрещены.

Дополнения r1:
- Локальный долговечный эмулятор банковского партнёра SandboxRail. Отдельная
  SQLite БД, стабильный reference, проверка digest, повтор не создаёт новую
  операцию, потеря ответа после commit, signed callback, постраничная выписка
  с opening/closing, debit/credit, локальная проверка неизменности.
- Offline reconciliation: непрерывность остатков, повторные/отсутствующие
  записи, несовпадение реквизитов, неопределённое состояние, unmatched entries.
  Только отчёт; не проводит денег, не подтверждает подлинность источника и не
  заменяет сверку с доверенной банковской выпиской.
- Старые HTTP submit/unknown блокируются: новые операции идут через
  /v3/rail/intents/{iid}/claim и /result. Старые методы Python оставлены для
  тестов прежних сценариев. Прямой доступ к БД запрещён внешним клиентам.
- PostgreSQL E2E-тесты: потерянный ответ, депозит, вывод, отказ, независимая
  выписка, сверка и корректный остаток. Требуют реальной тестовой БД.

## Приёмка блока 2
Внутреннее ядро: реализованы базовые комиссии, полные возвраты и внутренние
chargeback, risk/compliance, consent, двойная запись, резервирование,
неоднозначная отправка, сверка и локальный адаптер. Не считать сертифицированным
или полностью готовым к банкам без зелёных PG-тестов и независимого аудита.

Внешние и оставшиеся gates: реальный адаптер по спецификации партнёра,
KYC/AML/sanctions data sources, частичные возвраты и внешний dispute/chargeback
по правилам партнёра, комиссии/налоги/округление по договору, end-of-day
settlement и непрерывность проверенных выписок реального счёта, юридическая
модель средств, согласованные SLA и сертификация. Эмулятор не реализует
банковский протокол или реальный денежный остаток. Нет live activation.

Установка: только spyderpay-core-update-v007-r1.zip в корень репозитория.
Постоянный workflow и защищённые bootstrap файлы не изменены.

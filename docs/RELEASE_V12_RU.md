# 0.12.0 — интеграция с действующим kepler-spider

Накопительный релиз для pre-license окружения. Схема PostgreSQL 9 сохранена.
Не является разрешением на проведение реальных платежей.

- GET /v3/accounts: явный customer/sandbox/real_money=false, ограничение выдачи и has_more.
- GET /v3/accounts/{account_id}/activity: последние проводки только своего счёта, без раскрытия чужих персональных данных.
- POST /v3/invoices/{invoice_id}/resolution: проверка владельца, суммы, продавца, состояния и факта проводки. Неоплаченный просроченный счёт закрывается транзакционно. Неопределённый результат не является основанием для повторного списания.
- POST /v3/transfers/resolution и /v3/transfers/cancel: проверка исходного идентификатора, атомарная блокировка позднего запроса с тем же idempotency key, либо возврат фактического чека. Отмена не возвращает уже переведённые средства.
- Swift SDK: контракт v0.12, история, переводы, восстановление платежей, OAuth redirect validation. Отдельный ZIP интегрирует этот SDK в Console.

Установка: загрузить spyderpay-core-update-v012.zip в корень kepler-pay, дождаться Verify/Apply существующего workflow. Затем загрузить console-update-spyderpay-v012.zip в kepler-spider. Не менять YAML. Установщик кошелька не заменяет Xcode build.

Обязательные проверки: GitHub PostgreSQL CI (включая конкурентные операции), развёртывание изолированного staging, реальный IdP и подтверждение совместимости MFA, проверка Xcode на устройстве, физическая карта с утверждённым applet/AID, независимый аудит. Действующие банковские договоры, KYC-провайдеры, сертификация и разрешения не входят в релиз. Никаких реальных UZS или конфигурации production в архиве.

# SpyderPay Core v0.2 — большой блок обновления

## Что изменилось по сравнению с v0.1

- НОВОЕ: PostgreSQL 16 схема и processor с двойной записью, отложенными проверками равенства проводок, атомарным списанием, tenant isolation и outbox.
- НОВОЕ: service-to-service HMAC API с защитой от повторов, DB request rate bucket, ролевым разделением.
- НОВОЕ: invoice 15-минутный по умолчанию, проверка срока, безопасные возвраты, заморозка счетов, проверка лимитов, сверка.
- НОВОЕ: банк-адаптерный интерфейс и негативные тесты примерного webhook signature protocol.
- НОВОЕ: PostgreSQL concurrency+integrity suite и security unit suite; GitHub Actions тестируют реальные PostgreSQL операции после наложения ZIP.
- НОВОЕ: threat model, эксплуатационные runbooks, launch gate, API v2.
- СОХРАНЕНО: локальный SQLite демонстратор и предыдущие tests, без нарушения обратной совместимости по умолчанию.

## Установка

**Новый репозиторий:** архив `spyderpay-core-v02-initial-repo.zip` содержит всю кодовую базу и workflow; распаковать в пустой приватный репозиторий, сделать один initial commit.

**Старый v0.1:** сначала обычным Git-коммитом добавить содержимое `spyderpay-core-v02-actions-bootstrap.zip` (`.github/workflows/`, `scripts/cleanup_generated.py`, `tools/`, `pyproject.toml`, `Makefile`, `.gitignore`, `README.md`). Это одноразовая установка инфраструктуры. Только затем положить в корень `spyderpay-core-update-v002.zip`, GitHub Actions автоматически распакует новые Python-файлы/тесты/документацию.

*Безопасность установщика:* только разрешённые папки, нет изменения `.github`/scripts и секретов через upload ZIP, нет произвольной очистки. Удаляются успешно обработанный ZIP и явные временные файлы, но не исходники.

## Блокеры честного объявления production-ready

Текущую PostgreSQL реализацию нужно впервые подтвердить в окружении с работающей PostgreSQL 16; в локальной среде этой сессии СУБД и драйвер psycopg не установлены. Репозиторий содержит CI-интеграционный набор. Также отсутствуют реальные банки, полная модель расчётов, OIDC для конечных пользователей, независимый security audit и лицензирование. Сборка iOS здесь не менялась; переключатель Fiat/Crypto находится в отдельном ранее выданном wallet patch и всё ещё требует подключения к действующему root view.
